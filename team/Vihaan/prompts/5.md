## 🏢 2. Subgrid Building Placement Inside Districts
- Each district contains its assigned ~10–11 files.
- Place buildings within the district on a **4 x 3 local subgrid** (4 columns along X, 3 rows along Z):
  - Slot spacing: Building footprint is `0.9` units + `0.2` units gap = `1.1` unit pitch.
  - Subgrid width: `3 * 1.1 = 3.3` units.
  - Subgrid depth: `2 * 1.1 = 2.2` units.
  - Local origin offset:
    `localStartX = districtCenterX - 3.3 / 2;`
    `localStartZ = districtCenterZ - 2.2 / 2;`
- **Deterministic Placement:**
  - Sort files within each folder alphabetically by `file.path` before placement.
  - Slot index `i` maps to `localCol = i % 4`, `localRow = Math.floor(i / 4)`.
  - Unused subgrid slots (11th and 12th slots in a 4x3 grid) remain empty streets.
- **Coordinate Assignment:**
  ```javascript
  building.position.x = localStartX + (i % 4) * 1.1;
  building.position.z = localStartZ + Math.floor(i / 4) * 1.1;
  building.position.y = 0; // Base rests firmly on ground plane
  ```
