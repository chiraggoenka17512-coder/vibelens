THE REACHABILITY THEOREM

Static Lists Are Meaningless Without Execution Flow

In software security, an attack surface requires three elements:

  1. 1. Untrusted input entry point (HTTP route, CLI arg).
  2. 2. Propagation path through local application code.
  3. 3. Execution sink into the vulnerable library function.

If step 2 does not exist, the vulnerability is dormant phantom noise. VibeLens checks that exact path across the codebase AST call-graph.
