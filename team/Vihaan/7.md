# Prompt 7: Idle Sway

> **Instruction:** Add a subtle, ambient idle sway to the isometric camera after the entry animation finishes to keep the scene organic while scroll is stationary.

---

## 🌊 1. Sway Kinematics & Mathematics
- **Angular Deviation:** Maximum orbit deviation of **2 degrees** (`± 2°`) around the global Y-axis.
- **Harmonic Oscillation:**
  ```javascript
  const maxAngle = (2 * Math.PI) / 180; // 2 degrees in radians
  const angle = Math.sin(time * 0.25) * maxAngle;
  ```
- **Period:** Approximately `25 seconds` per complete sway cycle (`2 * Math.PI / 0.25 ≈ 25.13s`).
- **Orbital Rotation:**
  - Base camera position is `(x: 20, y: 20, z: 20)`.
  - Rotate the base coordinate around the vertical Y-axis:
    ```javascript
    const baseRadiusXZ = Math.hypot(20, 20); // ~28.284 units
    const baseAngle = Math.atan2(20, 20);   // PI / 4 (45 degrees)
    const currentAngle = baseAngle + angle;
    
    camera.position.x = baseRadiusXZ * Math.cos(currentAngle);
    camera.position.z = baseRadiusXZ * Math.sin(currentAngle);
    camera.position.y = 20; // Fixed height maintains constant isometric pitch
    camera.lookAt(0, 0, 0);
    ```

---

## 🛡️ 2. Execution Guardrails
1. **Activation Gate:**
   - Sway must start **only** after the entry animation completes:
   ```javascript
   let isEntryComplete = false;
   // Set isEntryComplete = true in GSAP onComplete callback
   ```
2. **Hover Pause:**
   - While the user is actively hovering over any building in Prompt 8, set `swayPaused = true`.
   - Freezing camera sway on hover prevents the screen-projected hover tooltip from trembling or drifting.
3. **Viewport Caching:**
   - Sway calculation inside the `requestAnimationFrame` render loop must halt when the section is scrolled out of view (`isSectionVisible === false`).
