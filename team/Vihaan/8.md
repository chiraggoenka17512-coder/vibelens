# Prompt 8: Hover Lift and Label

> **Instruction:** Add pointer hover interactions for live buildings. Dead code buildings are non-interactive. Ensure tooltips project smoothly into screen coordinates.

---

## 🎯 1. Layer-Isolated Raycasting
- Initialize `THREE.Raycaster` and a `THREE.Vector2` pointer vector.
- Listen to `pointermove` on `#city-container`:
  ```javascript
  const rect = container.getBoundingClientRect();
  pointer.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
  pointer.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
  ```
- **Layer Masking:**
  - Raycaster checks `camera.layers` mask.
  - Live buildings reside on **Layer 0**. Dead code buildings reside on **Layer 1**.
  - Query intersections against live building meshes only:
    ```javascript
    raycaster.setFromCamera(pointer, camera);
    const intersects = raycaster.intersectObjects(interactiveMeshes);
    ```

---

## 🏗️ 2. Tactile Lift Physics
- Track active hover target in `let hoveredBuilding = null`.
- **On Enter:**
  - GSAP tween `building.position.y` to `0.15` over `0.2s` with `ease: "power2.out"`.
  - Pause camera idle sway: `swayPaused = true`.
- **On Leave:**
  - GSAP tween `building.position.y` back down to `0` over `0.2s`.
  - Unpause camera idle sway: `swayPaused = false`.
- **Single-Target Invariant:** Only one building may be lifted at any given instant.

---

## 🏷️ 3. Dynamic Screen-Projected Tooltip (`#city-label`)
- Add an HTML tooltip `<div id="city-label">` inside `#city-container`:
  ```css
  #city-label {
    position: absolute;
    pointer-events: none;
    z-index: 20;
    background: rgba(10, 13, 17, 0.92);
    color: #FFFFFF;
    font-family: 'JetBrains Mono', monospace;
    font-size: 13px;
    line-height: 1.4;
    padding: 8px 12px;
    border-radius: 4px;
    white-space: nowrap;
    transform: translate(-50%, -100%);
    opacity: 0;
    transition: opacity 0.15s ease-out;
  }
  ```

### Tooltip Content
- **Line 1 (File Path):** e.g. `src/api/auth.ts` (`#FFFFFF`).
- **Line 2 (Metrics):** e.g. `412 lines` (`#A1A1AA` or `#FFFFFF`).
- **Line 3 (Flagged Only):** If `file.flagged === true`, append a third line:
  `<div style="color: #F2B95A;">flagged</div>`

### Coordinate Projection
In the render loop, while `hoveredBuilding` is active:
```javascript
const topCenter = new THREE.Vector3(
  hoveredBuilding.position.x,
  hoveredBuilding.userData.height + hoveredBuilding.position.y,
  hoveredBuilding.position.z
);
topCenter.project(camera);

const screenX = (topCenter.x * 0.5 + 0.5) * container.clientWidth;
const screenY = (-topCenter.y * 0.5 + 0.5) * container.clientHeight;

label.style.left = `${screenX}px`;
label.style.top = `${screenY - 12}px`; // 12px offset above building roof
label.style.opacity = '1';
```

## ✅ Acceptance Check
Before moving to Prompt 9, confirm:
1. Hovering over any live building lifts it by `0.15` units smoothly.
2. The tooltip displays the correct file path, line count, and positions `12px` above the building top.
3. Moving the mouse to another building cleanly resets the prior building and lifts the new one.
4. Flagged orange buildings display the extra `"flagged"` line in `#F2B95A`.
5. Hovering over dead code outlines triggers **zero** lift and **zero** tooltip.
6. Camera sway freezes while hovering and resumes upon mouseout.
