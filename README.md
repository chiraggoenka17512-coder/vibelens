## 🎯 The Problem in Plain English

Millions of developers, students, and founders are now **"vibe coding"** using tools like Cursor, Claude Code, Bolt, and v0. By writing prompts instead of manual code, complete applications are generated in hours.

**However, after 24 to 48 hours, projects suffer from the "Vibe Coding Hangover":**
1. **Codebase Slop & Phantom Duplication:** The AI forgets what it wrote earlier and continuously hallucinates duplicate helper functions across different folders (e.g., writing 4 different date/string parsers), leaves dead components, and abandons unused npm packages.
2. **Context Window Poisoning & Token Burn:** Every subsequent prompt requires passing project files into the LLM context window. Bloated duplicate code and dead files increase token costs by ~40%, slowing replies and triggering model hallucinations.
3. **CVE Alert Fatigue:** Scanners like Dependabot and Snyk flood developer inboxes with 40+ "Critical CVE" alerts. Yet in over 85% of cases, the vulnerability is in dead, uncalled code inside the package. Developers suffer alert fatigue and end up ignoring real threats.
4. **Generic "AI Slop" Frontends:** Interfaces generated by AI look like identical, generic toys: flat white cards, pastel purple gradients, and bloated 50-class Tailwind div-soups.
5. **The Black-Box Terror:** Because developers didn't write the 80 sprawling files, they cannot visualize what depends on what, terrified to touch or clean anything.

## ⚡ The Solution: The 5 Core Pillars

```

│    X-Ray Galaxy  ││   De-Duplicator  │  │ 4-Tier CVE Filter│  │   De-Slop Engine ││   CLI Sentinel   │
└──────────────────┘└──────────────────┘  └──────────────────┘  └──────────────────┘└──────────────────┘
```

1. **3D Spatial X-Ray Galaxy (Three.js WebGL):** Ingests any GitHub repo and renders an interactive 3D galaxy. Healthy code glows emerald, duplicate helper slop forms yellow clusters, silenced phantom CVEs display as green shields, and true zero-day attack paths illuminate in pulsing red lasers.
2. **ReachableSec 4-Tier SAST Engine:** Traces live Abstract Syntax Tree (AST) call-graphs from public API routes to dependencies. Classifies security threats into **`Reachable`**, **`Likely`**, **`Unknown`**, and **`Unreachable`** (silencing 88% of false alarms without compromising dynamic reflection).
3. **Pre-Prompt MCP Server (`@modelcontextprotocol/sdk`):** Native Model Context Protocol tools (`find_existing_utility`, `check_package`) that Cursor and Claude Code query *before* generating code, stopping duplication at the source.
4. **Interactive Blast Radius Inspector:** Click any node in the 3D mesh to instantly see every upstream route that breaks if the file is deleted, and every downstream package it requires (solving Problem #5).
5. **Frontend De-Slop Engine (CrashLens Reskin):** Ingests messy, generic AI frontend code and compiles it into the high-craft CrashLens industrial design language (obsidian `#09090b`, CAD blueprint crosshairs, monospace status chips, and glassmorphic panels) with a live split slider.
6. **VibeWatcher CLI Sentinel (`npx vibelens watch`):** A 1Hz background terminal daemon that catches duplicate functions and insecure packages in real time during prompting.
7. **Zero-Token ContextRelay Engine:** A deterministic AST state snapshot (`.vibelens/handover.json`) that enables lossless context transfer between agents (Cursor, Claude Code, Windsurf, or new chats) in ~380 tokens—delivering a 99.2% token savings over raw code dumps.
8. **Test-Gated Safe-Merge PR:** Automatically executes the repository's native test suite (`npm test`) before opening an authenticated GitHub Pull Request.

## 🛠️ The Technology Stack (100% JS / TS / React)

* **Frontend Framework:** Next.js 15 (App Router), React 19, TypeScript
* **3D Visualizer:** Three.js via `@react-three/fiber` and `@react-three/drei`
* **Styling & Components:** Tailwind CSS, `shadcn/ui` (Radix React Primitives), Lucide Icons
* **Authentication & Dev Keys:** Clerk (GitHub OAuth, Team RBAC, API Keys)
* **Database & Storage:** Supabase (Managed PostgreSQL)
* **Type-Safe ORM:** Drizzle ORM (`drizzle-orm`, `drizzle-kit`)
* **Edge Caching & Telemetry Bus:** Upstash Redis (Serverless edge memory)
* **Static Analysis & AST:** `@babel/parser`, `@babel/traverse`, `es-module-lexer`
* **AI Agent Integration:** `@modelcontextprotocol/sdk` (JSON-RPC over stdio)
* **Terminal Daemon & Git:** Node.js, `commander`, `chokidar`, `@octokit/rest`
