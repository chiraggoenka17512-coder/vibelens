[ THE INSIGHT // THE COMPILER PRINCIPLE ]

A vulnerability matters only if a path exists from an entry point to the vulnerable code.

Manifest-level scanners assume that importing a package exposes its entire attack surface. Compiler science proves otherwise: execution is a directed graph.

VibeLens traverses the AST to verify whether an actual execution path reaches the vulnerable function.
