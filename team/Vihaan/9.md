# Prompt 9: Click-to-Trace Red Arc

> **Instruction:** Add the click interaction that animates a pulsing red reachability arc from the public route entry point to any clicked flagged (vulnerable) building.

---

## 🚩 1. Public Route Entry Marker
- **Spatial Position:** Left perimeter of the city grid at `(-10.5, 0.1, 0)`.
- **Mesh Marker:**
  - `THREE.CircleGeometry(0.18, 32)`.
  - Rotate flat: `circle.rotation.x = -Math.PI / 2`.
  - Material: `THREE.MeshBasicMaterial({ color: 0xFF4D4D })`.
- **Text Tag:**
  - Place a technical label reading `"public route."` directly above the marker.
  - Styling matches Prompt 8: `#FF4D4D` accent, `JetBrains Mono 12px`, translucent dark capsule.

---

## 👆 2. Click Interaction & Event Filtering
Listen to pointer clicks / `click` event on `#city-container`:
1. **Raycast Detection:**
   - If click hits a **flagged building** (`file.flagged === true`):
     - If an arc already exists, clear it immediately.
     - Trigger the new bezier laser arc to this building.
   - If click hits a **non-flagged live building** or **dead code**:
     - Ignore the click (maintain existing arc if one is present).
   - If click hits **empty space** or the ground plane:
     - Clear and dispose the active arc.

---

## 📉 3. Quadratic Bezier Curve Geometry
- **Start Point ($P_0$):** `new THREE.Vector3(-10.5, 0.1, 0)`.
- **End Point ($P_2$):** Top-center of target building:
  ```javascript
  const end = new THREE.Vector3(
    target.position.x,
    target.userData.height + target.position.y,
    target.position.z
  );
  ```
- **Control Point ($P_1$):**
  - Midpoint along X and Z:
    `midX = (start.x + end.x) / 2; midZ = (start.z + end.z) / 2;`
  - High apex arc:
    `midY = Math.max(start.y, end.y) + 3.0;`
  - `const control = new THREE.Vector3(midX, midY, midZ);`
- **Curve Sampling:**
  ```javascript
  const curve = new THREE.QuadraticBezierCurve3(start, control, end);
  const points = curve.getPoints(200);
  ```

---

## 💡 4. Double-Line Laser & Glow Mesh
Construct two line segments from the sampled points:
1. **Core Laser Line:**
   - `THREE.Line` with `LineBasicMaterial({ color: 0xFF4D4D, transparent: true, opacity: 1.0 })`.
2. **Atmospheric Glow Line:**
   - Duplicate line with `LineBasicMaterial({ color: 0xFF4D4D, transparent: true, opacity: 0.35 })`.
   - Offset vertical position by `y += 0.02` units to eliminate depth collision.
3. Both line geometries start with `geometry.setDrawRange(0, 0)`.

---

## 🎬 5. Laser Animation & Continuous Pulse
1. **Growth Animation:**
   - Use GSAP on a proxy object `{ progress: 0 }`:
     ```javascript
     gsap.to(proxy, {
       progress: 200,
       duration: 0.8,
       ease: "power1.inOut",
       onUpdate: () => {
         const count = Math.floor(proxy.progress);
         mainGeom.setDrawRange(0, count);
         glowGeom.setDrawRange(0, count);
       },
       onComplete: () => startArcPulse()
     });
     ```
2. **Idle Breathing Pulse:**
   - After the 0.8s draw finishes, oscillate core line opacity between `0.6` and `1.0` using a harmonic sine wave with a 2-second period:
     ```javascript
     coreMaterial.opacity = 0.8 + 0.2 * Math.sin(clock.getElapsedTime() * Math.PI);
     ```

---

## 🧹 6. Clean Arc Teardown (Leak Prevention)
When clearing an existing arc:
1. Stop the GSAP growth tween and pulse loop.
2. Tween line opacity from current value to `0` over `0.3s`.
3. Call `scene.remove(arcGroup)`.
4. Explicitly dispose line geometries and materials (`geom.dispose()`, `mat.dispose()`).

---

## ✅ Acceptance Check
Before moving to Prompt 10, verify:
1. Clicking an orange flagged building traces a sharp red laser from the public route marker over `0.8s`.
2. Upon reaching the building, the laser pulses gently without framerate drops.
3. Clicking empty ground fades and destroys the laser cleanly.
4. Clicking a different flagged building replaces the prior path with a new arc.
5. Clicking regular blue buildings does not produce errors or phantom arcs.
6. Memory audit: repeatedly drawing and clearing arcs does not leak WebGL buffers.
