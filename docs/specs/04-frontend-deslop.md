# Spec 04: Frontend De-Slop Engine (CrashLens Aesthetic Upgrade)

> **Module:** AI Frontend Compiler & Reskinner  
> **Output Language:** CrashLens Industrial Telemetry Design System  
> **Components:** Radix React Primitives + Tailwind CSS + Interactive Split Slider

---

## 1. Overview
Inspects generic AI-generated frontend components (from v0, Bolt, or ChatGPT) and automatically compiles them into high-craft, dark-mode production interfaces inspired by the CrashLens design language.

## 2. Refactoring Transformations
1. **Background & Atmosphere:** Replaces flat white/gray containers with pitch-black obsidian (`#09090b`), CAD blueprint crosshairs, and dot-matrix grids.
2. **HUD Telemetry Chips:** Wraps raw numbers in monospace status chips: `[STATUS: ACTIVE // 12ms]`, `[DAG_NODES: 72]`.
3. **Card & Panel Upgrades:** Converts generic drop-shadow cards into glassmorphic panels (`backdrop-blur-md bg-zinc-950/60 border border-white/10`).
4. **Micro-Interactions:** Injects spring hover scales and subtle border glow pulses.

## 3. Interactive Split Slider Component
* Uses custom CSS clip-path or React comparison slider.
* Left side shows messy AI-generated purple/white slop; right side shows the live CrashLens industrial interface.
