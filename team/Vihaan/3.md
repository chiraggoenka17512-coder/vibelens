## 📋 2. File Object Shape (Strict Schema)
Every object in the array must strictly conform to this 6-key structure:
```typescript
interface RepoFile {
  path: string;         // Full relative path, e.g. "src/api/auth.ts"
  loc: number;          // Lines of code (integer between 20 and 900)
  folder: string;       // Directory group, e.g. "src/api"
  dead: boolean;        // True if file is unreferenced / dead code
  flagged: boolean;     // True if file contains a reachable vulnerability
  route: "public" | null; // "public" for flagged files, null for all others
}
```

## 🎲 3. Deterministic Seeded Generator (`mulberry32`)
To guarantee that the city layout is identical across page reloads and browser sessions, use a deterministic seeded PRNG:
```javascript
function mulberry32(seed) {
  return function() {
    let t = seed += 0x6D2B79F5;
    t = Math.imul(t ^ t >>> 15, t | 1);
    t ^= t + Math.imul(t ^ t >>> 7, t | 61);
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  }
}
const rng = mulberry32(42);
```

## 📂 4. Dataset Generation Rules
1. **Target Count:** Exactly **64 files** in total.
2. **Folders (in this exact sequence):**
   - `"src/api"`
   - `"src/auth"`
   - `"src/db"`
   - `"src/utils"`
   - `"src/ui"`
   - `"src/workers"`
3. **Distribution:** Distribute the 64 files across the 6 folders as evenly as possible (approx 10–11 files per folder).
4. **File Names & Extensions:**
   - 12 plausible engineering names per folder (e.g., `routes`, `handlers`, `middleware`, `auth`, `users`, `billing`, `webhooks`, `rate-limit`, `errors`, `validators`, `upload`, `health`).
   - Extensions:
     - `src/api`, `src/auth`, `src/db`, `src/workers` → `.ts`
     - `src/utils` → `.js`
     - `src/ui` → `.tsx`
5. **LOC Distribution (Lines of Code):**
   - Integer values between `20` and `900`.
   - Skewed distribution: ~80% of files between `40` and `300` LOC; ~10% small files (`< 40`); ~10% large monoliths (`> 600`).
6. **Dead Code Flag (`dead`):**
   - Set `true` for approximately 12% of files (~8 files).
7. **Security Flag (`flagged`):**
   - Set `true` for approximately 8% of files (~5 files).
   - **Invariant:** A flagged file is **never** dead (`if (file.flagged) file.dead = false`).
8. **Route (`route`):**
   - Must be `"public"` for every file where `flagged: true`.
   - Must be `null` for all other files.
