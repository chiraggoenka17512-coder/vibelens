# Prompt 4: Building Geometry and Materials

> **Instruction:** Convert each repo file object into a 3D isometric building. Build all buildings at the scene origin for now to verify geometry and face materials.

---

## 📏 1. Sizing & Base Pivot Rules
- **Footprint:** Every building has a uniform square footprint of `0.9 x 0.9` world units on the ground.
- **Height Formula:**
  ```javascript
  const height = Math.min(file.loc * 0.012, 8.0);
  ```
  - Capped at a maximum ceiling of `8.0` units.
- **Ground Anchor (Pivot at Base):**
  - Standard Three.js `BoxGeometry` centers its origin at its geometric midpoint.
  - To ensure that scaling (`scale.y`) in Prompt 6 expands **upward from the ground**, translate the geometry upward by `height / 2`:
  ```javascript
  const geometry = new THREE.BoxGeometry(0.9, height, 0.9);
  geometry.translate(0, height / 2, 0);
  ```
  - Now `y = 0` is permanently anchored to the building's bottom face.

---

## 🎨 2. Shading & Multi-Material Face Groups
Use `MeshStandardMaterial` with `flatShading: true` to produce the sharp, tactile CAD/blueprint isometric look.

A Three.js `BoxGeometry` accepts an array of 6 materials corresponding to:
- Index 0: Right face (`+X`)
- Index 1: Left face (`-X`)
- Index 2: Top face (`+Y`)
- Index 3: Bottom face (`-Y`)
- Index 4: Front face (`+Z`)
- Index 5: Back face (`-Z`)

### A. Default Live Buildings
- **Top face (`+Y`):** `#7A8BA0`
- **Front & Back (`+Z`, `-Z`):** `#4A5A6E`
- **Sides & Bottom (`+X`, `-X`, `-Y`):** `#3B4A5C`

### B. Flagged Buildings (`flagged: true`)
- **Top face (`+Y`):** `#F2B95A`
- **Front & Back (`+Z`, `-Z`):** `#E8A33D`
- **Sides & Bottom (`+X`, `-X`, `-Y`):** `#9A6524`

### C. Dead Code Buildings (`dead: true`)
- Dead code renders as a faint, ghosted translucent silhouette with subtle wireframe edges:
  1. **Translucent Fill Mesh:**
     - `MeshBasicMaterial({ color: 0x7A8BA0, transparent: true, opacity: 0.12, depthWrite: false })`
  2. **Ghost Outline Edges:**
     - `const edges = new THREE.EdgesGeometry(geometry);`
     - `const line = new THREE.LineSegments(edges, new THREE.LineBasicMaterial({ color: 0x7A8BA0, transparent: true, opacity: 0.35 }));`
- **Raycast Layering:** Assign dead building meshes to `layers 1` (`mesh.layers.set(1)`), keeping live interactive buildings on layer 0. The raycaster will only query layer 0 so dead code never obstructs clicks or hovers.
