# Prompt 6: Entry Animation (Back-to-Front Wave)

> **Instruction:** Animate the city entering the scene when `#repo-city` scrolls into view. The animation plays once and does **not** scrub with scroll position.

---

## ⚡ 1. ScrollTrigger Configuration
- Register ScrollTrigger with GSAP: `gsap.registerPlugin(ScrollTrigger);`
- Attach trigger to `#repo-city`:
  ```javascript
  ScrollTrigger.create({
    trigger: "#repo-city",
    start: "top 70%",
    once: true,
    onEnter: () => playEntryAnimation(),
  });
  ```
- **Invariant:** Must be `once: true` — do not replay or reverse when scrolling up and down.

---

## 🌊 2. Back-to-Front Staggered Rise Wave
- **Initial State:** On initial scene build, set every building's `scale.y = 0.001` (collapsed flat on the ground).
- **Target State:** `scale.y = 1.0` (full vertical height).
- **Spatial Wave Sorting:**
  - Sort the `buildings` array by distance from the back:
  ```javascript
  const sortedBuildings = [...buildings].sort((a, b) => {
    return (a.position.x + a.position.z) - (b.position.x + b.position.z);
  });
  ```
- **Timeline Specs:**
  - Total wave span: `1.2 seconds`.
  - Individual building rise duration: `0.6 seconds`.
  - Stagger delay: `(1.2 - 0.6) / sortedBuildings.length` per building.
  - Ease: `"power2.out"`.
- **Anchor Invariant:** Because geometry was translated up by `height / 2` in Prompt 4, scaling `scale.y` from 0.001 to 1.0 makes the building grow smoothly upward from the ground plane without sinking.

---

## 🎥 3. Camera Settle Transition
- Concurrently with the building wave, animate the orthographic camera settling into its final isometric stance:
  - **Initial Camera Position:** `(14, 26, 26)`.
  - **Final Camera Position:** `(20, 20, 20)`.
  - **Duration:** `1.4 seconds`.
  - **Ease:** `"power2.inOut"`.
- **Update Hook:**
  ```javascript
  gsap.to(camera.position, {
    x: 20,
    y: 20,
    z: 20,
    duration: 1.4,
    ease: "power2.inOut",
    onUpdate: () => {
      camera.lookAt(0, 0, 0);
      camera.updateProjectionMatrix();
    }
  });
  ```

---

## ✅ Acceptance Check
Before moving to Prompt 7, verify:
1. Scrolling `#repo-city` past 70% viewport triggers the animation cleanly once.
2. Buildings rise in a perceptible diagonal ripple wave from the back corner to the front edge.
3. The orthographic camera swoops subtly from `(14, 26, 26)` and locks into `(20, 20, 20)`.
4. Scrolling away and returning to the section does **not** replay the rise animation.
