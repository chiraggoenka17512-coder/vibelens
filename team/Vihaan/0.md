> **Instruction:** You are building one section of an existing scroll-driven landing page. Read this entire prompt before writing code. Attach the reference screenshot to every prompt. Match it closely.

---

## 📌 Scope Notes
- The "You are sharing" card at the right edge of the screenshot belongs to another part of the site, so it is **excluded**.

## 📦 Output Requirements
- **Deliverable:** Exactly one self-contained HTML file named `repo-city.html`.
- **Zero Extra Dependencies:** No libraries, fonts, icons, or images beyond the ones explicitly listed below.
- **Scroll Integrity:** Do **NOT** add `OrbitControls`, drag-to-rotate, or any mouse interaction that takes control away from page scrolling.
- **Zero Hallucination / Scope Control:** Do not invent copy, data, colors, or features that are not specified. If something is unspecified, choose the simplest option and record it in a comment block at the very top of the file titled `ASSUMPTIONS`.
