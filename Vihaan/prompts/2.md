# Prompt 2: Three.js Scene and Isometric Camera

> **Instruction:** Add the Three.js WebGL scene inside `#city-container`. Do not add buildings yet. Match the isometric orientation and light setup.

---

## 📦 1. Imports
- Import `* as THREE` from `"three"` using the importmap defined in Prompt 0.
- Do **NOT** import any Three.js addons (strictly **no** `OrbitControls`, no `GLTFLoader`).

---

## ⚙️ 2. WebGL Renderer
- Initialize: `new THREE.WebGLRenderer({ antialias: true, alpha: true })`.
- Set alpha so the HTML section background gradient and vignette show through cleanly.
- Set clear color to transparent (`0x000000, 0`).
- Cap device pixel ratio: `renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))`.
- Size: fill `#city-container` completely.
- Append the canvas element to `#city-container`.
- Implement dynamic resize handling:
  - Listen to window resize and attach a `ResizeObserver` to `#city-container` to update renderer dimensions and camera projection matrix.

---

## 📐 3. Isometric Orthographic Camera
- Use `THREE.OrthographicCamera` (this provides the authentic CAD/isometric look without perspective distortion).
- **Position:** `(20, 20, 20)`.
- **Target:** `camera.lookAt(0, 0, 0)`.
- **Up Vector:** `(0, 1, 0)`.
- **Frustum Calculation:**
  - Base height: `22` world units tall.
  - Calculate aspect ratio: `aspect = container.clientWidth / container.clientHeight`.
  - Frustum bounds:
    - `left = (-22 * aspect) / 2`
    - `right = (22 * aspect) / 2`
    - `top = 22 / 2`
    - `bottom = -22 / 2`
    - `near = 0.1`, `far = 1000`
- Recompute frustum bounds and call `camera.updateProjectionMatrix()` on container resize.

---

## 💡 4. Scene & Lighting Setup
- `scene.background = null` (strictly transparent).
- **Lights:**
  1. `THREE.AmbientLight(0xFFFFFF, 0.45)` — provides balanced base visibility.
  2. `THREE.DirectionalLight(0xFFFFFF, 0.9)` — position at `(-12, 24, 10)`, looking at `(0, 0, 0)`. This forms the upper-left key light giving high-contrast top and side face differentiation.
- Do **NOT** enable Three.js shadows (`castShadow = false`, `receiveShadow = false`).

---

## 🌐 5. Ground Plane & Grid
- **Invisible Raycast Ground:**
  - `THREE.PlaneGeometry(40, 40)`.
  - Rotate flat: `plane.rotation.x = -Math.PI / 2`.
  - Material: `MeshBasicMaterial` with color `#12171E` and `opacity: 0.0`, `transparent: true`.
- **Isometric Grid Helper:**
  - `new THREE.GridHelper(40, 40, 0x2A3847, 0x2A3847)`.
  - Position: `y = 0.001` so it hovers just a fraction above the ground plane without z-fighting.

---

## 🔄 6. Render Loop & Performance Optimization
- Standard `requestAnimationFrame` loop invoking `renderer.render(scene, camera)`.
- **Power Optimization:** Use an `IntersectionObserver` on `#repo-city`.
  - Pause the `requestAnimationFrame` loop when the section is scrolled off-screen.
  - Resume the loop immediately when the section enters the viewport.
